## Chronic pain related fMRI data
#### home assignment programming for psychologists 
Lorna Schlüter - completed on 6th December 2025
Data: https://neurosynth.org/analyses/terms/chronic%20pain/

This is a repository for a home assignment in the programming for psychologists course of VU's RM Cognitive Neuropsychology. The project visualizes fMRI data associated with the term chronic pain (see link above) in two different ways. It plots the functional data on top of anatomical brain images for all three planes and then shows a histogram of the voxel intensity distribution. 

Table of contents:
- anatomical.nii = anatomical MRI data
- chronic pain_uniformity-test_z_FDR_0.01.nii = functional MRI data related to chronic pain
- homeass.ipynb = jupyter notebook containing the aforementioned visualizations
- Bildschirmfoto 2025-12-06 um 20.01.09.png = Screenshot proof of pull request 

Packages required:
- nilearn
- nibabel
- matplotlib
